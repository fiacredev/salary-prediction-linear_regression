Salary Prediction Using Linear Regression

My first Machine Learning project 

In this project, I predict salary based on years of experience using a simple dataset. This is my first step into Machine Learning, exploring basic data visualization and building a Linear Regression model.

Project Goals
Explore and visualize the dataset.
Understand the relationship between experience and salary.
Train a Linear Regression model to predict salaries.

Why Linear Regression?

Linear Regression is used to predict numerical values when the relationship between input and output is approximately linear.

In this project:

Input: Years of Experience
Output: Predicted Salary
